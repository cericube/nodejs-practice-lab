당신은 시니어 백엔드 개발자입니다.

다음 코드에 대해 팀 개발자들이 쉽게 이해할 수 있도록
실무 수준의 코드 주석을 작성해 주세요.

주석 작성 규칙은 다음과 같습니다.

[주석 작성 원칙]

1. 코드가 "무엇을 하는지"보다
   "왜 그렇게 설계되었는지" 설명합니다.

2. 다음 구조를 사용합니다.

------------------------------------------------

1️⃣ Section Header

파일 내 주요 영역에는 다음과 같은 섹션 주석을 사용합니다.

예:

/**
 * =============================================
 * Pagination Utilities
 * =============================================
 */

------------------------------------------------

2️⃣ 함수 주석 형식

각 주요 함수에는 다음 구조를 사용합니다.

예:

/**
 * 게시글 목록 조회
 *
 * [Purpose]
 * 이 함수가 수행하는 역할 설명
 *
 * [Business Rules]
 * 적용되는 도메인 규칙 설명
 *
 * [Implementation Notes]
 * 주요 구현 방식 설명
 *
 * [Performance]
 * 성능 관련 고려사항
 *
 * [Security]
 * 권한 / 보안 관련 정책 (필요한 경우만)
 */

------------------------------------------------

3️⃣ 복잡한 로직 설명

Keyset pagination, concurrency control, index optimization
같은 로직에는 SQL 또는 알고리즘 예시를 포함합니다.

예:

/**
 * Keyset Pagination WHERE 조건
 *
 * ORDER BY viewCount DESC, id DESC
 *
 * WHERE
 *   viewCount < :value
 *   OR (viewCount = :value AND id < :id)
 */

------------------------------------------------

4️⃣ Inline 주석 규칙

- 단순 코드 설명 금지
- 설계 이유만 작성

❌ 잘못된 예

// 값이 없으면 true

⭕ 좋은 예

// title 검색만 기본 수행 (본문 검색은 Full Table Scan 비용이 큼)

------------------------------------------------

5️⃣ 주석 스타일

- JSDoc 형식 사용
- 한국어 설명 사용
- 너무 장황하지 않게 작성
- 팀원이 빠르게 이해할 수 있도록 작성

------------------------------------------------

6️⃣ 기존 코드 로직은 절대 변경하지 말고
주석만 추가하거나 개선하세요.
