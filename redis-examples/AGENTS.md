## 명령 실행 기준

- `redis-examples`에 `package.json`이 있으면 npm 명령은 `redis-examples` 폴더에서 실행한다.
- 예제 실행 스크립트가 있으면 임의 명령보다 기존 `npm run ...` 스크립트를 우선 사용한다.
- Redis 서버 실행이 필요한 검증은 로컬 Redis 사용 가능 여부를 확인한 뒤 진행한다.

## Redis 연결 기준

- Redis 연결 정보가 환경 변수, `.env`, 설정 파일, 또는 코드 상수 중 어디에서 관리되는지 먼저 확인한다.
- 비밀번호, 외부 호스트, 운영 환경 포트 같은 민감한 값은 하드코딩하지 않는다.
- 로컬 예제 기본값은 특별한 이유가 없으면 `localhost`와 `6379`를 사용한다.
- Redis 클라이언트 연결을 생성한 예제는 실행 종료 시 연결을 정리한다.
- Pub/Sub, Stream, Queue처럼 계속 실행되는 예제는 계속 실행되는 이유와 종료 방법을 알 수 있게 작성한다.

## 주석 작성 기준

- 주요 상수, 타입, 변환 함수, 서비스 메서드에는 학습자가 흐름을 이해할 수 있는 설명을 붙인다.
- JSDoc 주석은 다음 구조를 우선한다.
  - 첫 줄에 메서드나 함수의 목적을 짧게 쓴다.
  - 빈 줄 뒤에 `1.`, `2.`, `3.` 형식으로 처리 흐름을 순서대로 설명한다.
  - Redis 사용법이나 실습 의도가 있으면 `실습 포인트:` 섹션을 추가한다.
  - 실무상 주의할 점이 있으면 `참고:` 섹션을 추가한다.
- 타입 주석은 해당 타입이 어떤 입력, 출력, 저장 데이터, 응답 데이터로 쓰이는지 역할 중심으로 작성한다.
- Redis 명령과 데이터 구조는 현재 예제의 동작을 이해하는 데 필요한 범위에서 설명한다.
- Redis 함수 호출 주석은 아래의 별도 기준을 따른다.
- 코드 내부 주석은 복잡한 흐름을 보조하는 짧은 문장으로만 작성한다.
- 코드만 봐도 명확한 단순 대입, 단순 return, 단순 key 생성에는 불필요한 주석을 추가하지 않는다.
- 주석은 한국어로 작성하고, 기존 파일의 말투처럼 설명형 문장으로 통일한다.

### Redis 함수 호출 주석 작성 규칙

- Redis 함수를 호출하는 코드 바로 위에 **2줄 주석**을 작성한다.
- 첫 번째 줄은 **현재 코드에서 Redis를 사용하는 목적(용도)**을 설명한다.
- 두 번째 줄은 **Redis 명령의 핵심 동작과 반환값**을 설명한다.
- 조회 결과가 없을 때 `null`, `0`, 빈 배열 등이 반환되면 함께 작성한다.
- 코드의 동작에 영향을 주는 **주요 옵션**(`EX`, `NX`, `BLOCK`, `COUNT` 등)만 간략하게 설명한다.
- Redis CLI 명령어나 Node Redis 함수 시그니처를 그대로 작성하지 않는다.
- Redis 내부 구현보다는 **현재 코드에서 어떤 동작을 수행하는지** 이해할 수 있도록 작성한다.
- 동일한 설명이 이미 있는 경우 중복 작성하지 않는다.
- 단순 Key 생성, 일반 TypeScript 로직, Redis 연결 및 종료 코드에는 적용하지 않는다.
- Redis 고유 개념(Pending, Consumer Group, TTL 등)이 코드 이해에 필요한 경우에는 한 줄로 간단히 설명한다.

### 예시

```ts
// 특정 게시글의 현재 인기 점수를 조회합니다.
// 게시글이 랭킹에 없으면 null을 반환합니다.
const score = await redis.zScore(key, member);

// 알림 이벤트를 Stream에 저장합니다.
// 이벤트를 추가하고 생성된 메시지 ID를 반환합니다.
const messageId = await redis.xAdd(key, '*', event);

// Consumer Group에서 아직 전달되지 않은 새 작업을 읽습니다.
// 최대 count개를 1초 동안 기다리며, 메시지가 없으면 null을 반환합니다.
const result = await redis.xReadGroup(
  groupName,
  consumerName,
  [
    {
      key,
      id: '>',
    },
  ],
  {
    COUNT: count,
    BLOCK: 1000,
  },
);
```
